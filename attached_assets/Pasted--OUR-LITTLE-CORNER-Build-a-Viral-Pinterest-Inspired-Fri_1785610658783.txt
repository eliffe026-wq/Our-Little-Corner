# 💌 OUR LITTLE CORNER
### Build a Viral Pinterest-Inspired Friendship Day Web Experience

You are an award-winning Product Designer, UI/UX Designer, Creative Director, Motion Designer, and Senior Full Stack Engineer.

Your task is to build a COMPLETE production-ready web application called **Our Little Corner**.

This is NOT a greeting card.
This is NOT a static website.
This is NOT a normal web app.

It is an emotional, interactive experience between two friends.

Imagine opening a scrapbook your best friend secretly spent all night making just for you.

The website should make users smile, laugh, cry a little, take screenshots, and instantly want to send it to another friend.

The website should have extremely high viral potential.

────────────────────────────────────────

# MAIN CONCEPT

Every friendship gets its own private scrapbook.

User A creates a scrapbook.

User A sends the personalized link.

User B opens it.

Both friends continue building the scrapbook together.

Everything inside belongs ONLY to those two people.

Nobody else can view it.

The scrapbook keeps growing every time one of them visits.

Think of it as:

Pinterest
+
Scrapbook Journal
+
Notion
+
Spotify Wrapped emotions
+
Studio Ghibli softness
+
A friendship diary.
